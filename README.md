# 📚 Գրքի Ակումբ (Book Club Web Project)

## 📖 Նկարագրություն
«Գրքի Ակումբ»-ը ամբողջական frontend վեբ նախագիծ է՝ ստեղծված HTML, CSS և JavaScript-ով։  
Այն ներկայացնում է գրքային հարթակ՝ գրախոսություններով, գրախանութով, հեղինակների բաժնով և զամբյուղի (cart) համակարգով։

---

## 🚀 Ֆունկցիոնալություն

### 🏠 Գլխավոր էջ
- Hero section գեղեցիկ background image-ով
- Animated quote slider
- Էսթետիկ գրքային դիզայն

### 📖 Գրախոսություններ
- Գրքերի cards
- Նկար + նկարագրություն
- Արտաքին հղումներ

### 📊 Գրքեր (Table)
- Ամենաշատ կարդացված գրքերի աղյուսակ
- Responsive scroll mobile-ի համար

### 🛒 Գրախանութ (Shop)
- Գրքերի քարտեր (cards)
- Filter ըստ ժանրի (Վեպ, Ֆանտաստիկա, Դասական)
- Add to cart ֆունկցիա

### 🛍️ Զամբյուղ (Cart System)
- Ավելացնել / ջնջել գրքեր
- Քանակի փոփոխություն (+ / -)
- Ընդհանուր գումարի հաշվարկ
- Checkout modal

### 👨‍💻 Հեղինակներ
- Author cards
- Hover animation

### ✉️ Կապի ֆորմա
- Անուն, email, ժանր ընտրություն
- HTML validation

---

## 🧠 Օգտագործված տեխնոլոգիաներ

- HTML5
- CSS3 (Flexbox, Grid, Animations, Media Queries)
- JavaScript (Vanilla JS)
- Responsive Design
