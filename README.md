# 📚 Գրքի Ակումբ

Հայալեզու գրքի ակումբի կայք՝ գրախանութով, զամբյուղով, գրախոսություններով, հեղինակների բաժնով և բաժանորդագրությամբ։

---

## 🖥️ Կայքի նախադիտում

> Բացիր `index.html` ֆայլը բրաուզերում — ոչ մի կառուցման քայլ պետք չէ։

---

## ✨ Հնարավորություններ

- **Ռեսպոնսիվ դիզայն** — աշխատում է desktop, պլանշետ և բջջայինի վրա
- **Մեջբերումների սլայդեր** — CSS անիմացիայով
- **Գրախոսությունների բաժին** — քարտեր՝ hover էֆեկտներով և արտաքին հղումներով
- **Ամենաշատ կարդացված գրքերը** — ձևավորված աղյուսակ
- **Գրախանութ** — գրքեր կարելի է զտել ըստ ժանրի (Վեպ, Ֆանտաստիկա, Դասական)
- **Զամբյուղ** — սահող վահանակ, որտեղ կարելի է՝
  - Ավելացնել / հեռացնել գրքեր
  - Փոխել քանակը
  - Տեսնել ընդհանուր գինը (֏)
  - Կատարել պատվեր՝ հաստատման modal-ով
- **Հեղինակների բաժին** — hover անիմացիայով քարտեր
- **Կապի ձև** — ակումբին միանալու ձև՝ HTML5 վալիդացիայով
- **Ֆուտեր** — բաժանորդագրություն, նավիգացիա, կոնտակտային տվյալներ

---

## 📁 Նախագծի կառուցվածք

Նախագիծը բաղկացած է ընդամենը երկու ֆայլից՝

**`index.html`** — կայքի ամբողջ կառուցվածքը, բոլոր բաժինները և JavaScript-ը մեկ տեղում։

**`style.css`** — ոճավորումը, անիմացիաները և ռեսպոնսիվ breakpoint-ները։

---

## 🛠️ Օգտագործված տեխնոլոգիաներ

| Տեխնոլոգիա | Կիրառություն |
|---|---|
| HTML5 | Կառուցվածք, ձևեր, աղյուսակներ |
| CSS3 | Flexbox, Grid, `@keyframes`, `@media` |
| Vanilla JavaScript | Զամբյուղ, ֆիլտրում, modal, UI |
| Open Library Covers API | Գրքի կազմեր՝ ISBN-ով |
| Unsplash | Ֆոնային նկարներ |

---

## 📱 Ռեսպոնսիվ breakpoint-ներ

| Կետ | Դասավորություն |
|---|---|
| `> 1200px` | Լրիվ sidebar + լայն բովանդակություն |
| `≤ 1200px` | Նեղ sidebar (200px) |
| `≤ 900px` | Sidebar-ը վերևում հորիզոնական |
| `≤ 600px` | Մեկ սյան բջջային դասավորություն |

---

## 🛒 Զամբյուղի տրամաբանություն

Զամբյուղը կառավարվում է JavaScript-ի `cart` զանգվածով՝

```js
addToCart(name, price, btn)   // Ավելացնել գիրք (կամ ավելացնել qty-ն)
changeQty(name, delta)        // Փոխել քանակը, հեռացնել եթե 0 է
removeFromCart(name)          // Հեռացնել գիրքը
toggleCart()                  // Բաց / փակ անել զամբյուղի վահանակը
checkout()                    // Մաքրել զամբյուղը, ցուցադրել modal
```
